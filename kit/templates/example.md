# Booking a Meeting Room

> **Example document.** This file shows how a finished page looks when it is
> written from `template.md`. The content is illustrative only.

## Purpose

How to book a meeting room so that rooms are fairly shared and nobody is
double-booked.

## Scope

All employees using the office meeting rooms. Video-only meetings do not need
a room.

## Content

### Before you book

- Check whether a room is really needed; small check-ins work well on video.
- Pick the smallest room that fits the group.

### How to book

1. Open the shared company calendar.
2. Create the event and add the room as a guest.
3. Write a clear title, for example "Sprint planning - Team A".
4. Wait for the room to accept the invitation; if it declines, choose another.

### Rules

| Rule | Why |
| --- | --- |
| Maximum 2 hours per booking | Keeps rooms available for others |
| Cancel at least 1 hour before if plans change | Frees the room for colleagues |
| Leave the room clean and the screen switched off | Ready for the next meeting |
